# Planning history

These files are superseded planning and instruction notes, kept as history. They were the
design plans and task briefs of earlier milestones and moved here unchanged from the
repository root. They do not describe current behaviour and grant no live-run allowance;
where they disagree with the code or the current docs, the code and the current docs win.

Source comments that cite "plan N.M" (for example `plan 9.3`, `plan 16.4`) refer to
sections of `Harness_Agnostic_Workflow_Greenfield_Plan_2026-09-19.md` in this directory.

Current documentation:

- `README.md` - capability status, commands, limits, what is not implemented
- `docs/operations.md` - operator reference (commands, exit codes, approval, repair, recovery)
- `docs/architecture.md` - module map and data ownership
- `docs/adr/` - transport decision; `docs/batch-e-plan.md`, `docs/batch-i-integration-plan.md` - batch contracts
- `docs/m0-results.md`, `docs/m2-*.md` - recorded evidence (never rewritten)
- `AGENTS.md` and `docs/ai/agents/next-session.md` - working notes and the next priority
